# backend-fastapi

SW-EZ-Team의 Python FastAPI 기반 백엔드 저장소다.

## 개요

Python / FastAPI로 구현한 API 서버다. 빠른 개발 속도와 비동기 I/O 처리를 동시에 확보하는 것이 목표다.

## 기술 스택

- Language: Python (latest LTS)
- Framework: FastAPI
- Server: Uvicorn
- Database: 추후 확정

## 시작하기

```bash
# 의존성 설치
# pip install -r requirements.txt

# 개발 서버 실행
# uvicorn main:app --reload
```
