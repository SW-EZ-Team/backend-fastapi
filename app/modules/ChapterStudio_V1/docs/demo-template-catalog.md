# ChapterStudio_V1 데모 템플릿 카탈로그

## 목적

프론트 초안 입력값을 받아 1강 5장짜리 테스트 강의를 만들 때도 실제 ChapterStudio_V1의 큰 흐름을 유지한다. 슬라이드 안 실습, 강의 끝 퀴즈, 핵심노트, 과제, 음성대본은 서로 다른 산출물로 분리한다.

## 프론트 색상 기준

데모 화면은 `frontend-web/src/index.css`와 `Docs/Frontend_guide.md`의 토큰을 따른다.

| 역할 | 토큰 | 값 |
|---|---|---|
| 페이지 배경 | `--surface-page` | `#F9F8F3` |
| 카드 배경 | `--surface-card` | `#FFFDF7` |
| 본문 텍스트 | `--text-primary` | `#1F2A30` |
| 보조 텍스트 | `--text-secondary` | `#55646C` |
| 기본 강조 | `--accent-primary` | `#207B4C` |
| 선택 배경 | `--accent-soft` | `#E7F3E8` |
| 경고/오답 | `--state-danger` | `#C2425B` |
| 배지/주의 | `--state-warning` | `#FEE87E` |

## 템플릿 구조

프론트 select의 첫 항목은 `auto`이며, 주제 문자열을 보고 전용 템플릿을 자동 추천한다. 인물·통계·연구방법·물리·천문·지구과학·환경·경제·심리·사회·지리·공학·전자·미디어·건강·화학·생명·의과·코딩·언어·법·경영·예술·글쓰기·수학·실험·시험 키워드를 우선 판별하고, 맞는 규칙이 없으면 `foundation_overview`로 안전하게 시작한다.

| key | 라벨 | 5장 구성 | 사용 상황 |
|---|---|---|---|
| `concept_code` | 개념 + 코드 | 개념 지도 → 짧은 실습 → 코드 재현 | 개념과 구현을 함께 익힐 때 |
| `compare_practice` | 비교 + 실습 | 비교 지도 → 판별 실습 → 대조 코드 | 헷갈리는 개념의 경계를 잡을 때 |
| `debug_case` | 오류 분석 | 오류 증상 → 수정 코드 → 디버그 실습 | 실패 원인과 수정 기준을 익힐 때 |
| `exam_focus` | 시험 대비 | 출제 포인트 → 선지 판별 → 실전 예제 | 시험형 문제를 빠르게 대비할 때 |
| `visual_map` | 시각 지도 | 관계 지도 → 학습 비중 차트 → 지도 점검 | 구조와 우선순위를 먼저 볼 때 |
| `math_reasoning` | 수식 추론 | 직관 잡기 → 수식 전개 → 계산 실습 | 식의 의미와 적용 조건을 익힐 때 |
| `foundation_overview` | 기초 관점 | 왜 이 주제인가 → 관점 지도 → 자가 위치 확인 | 낯선 자유주제에 처음 진입할 때 |
| `process_flow` | 과정 흐름 | 단계 지도 → 단계 비중 → 순서 맞추기 | 단계·절차·메커니즘을 배울 때 |
| `cause_effect` | 원인·결과 | 인과 문장 → 인과 지도 → 원인 판별 | 인과관계와 조건을 구분할 때 |
| `data_analysis` | 데이터 해석 | 패턴 보기 → 해석 기준 → 그래프 읽기 | 표·그래프·실험 결과를 읽을 때 |
| `algorithm_trace` | 알고리즘 추적 | 문제 모델 → 상태 흐름 → 구현 추적 | 코딩 알고리즘을 학습할 때 |
| `system_design` | 시스템 설계 | 아키텍처 → 트레이드오프 → 설계 점검 | 소프트웨어·운영 구조를 볼 때 |
| `lab_protocol` | 실험 절차 | 실험 목표 → 절차 흐름 → 변수 통제 | 과학 실험·실습 설계가 필요할 때 |
| `chem_reaction` | 화학 반응 | 반응 직관 → 입자 관점 → 양적 관계 | 화학식·몰·보존을 배울 때 |
| `bio_system` | 생명 시스템 | 구조·기능 → 조절 원리 → 기능 판별 | 생명과학 구조와 기능을 연결할 때 |
| `clinical_reasoning` | 의과 추론 | 증상 프레임 → 감별 지도 → 판단 연습 | 의학·간호·임상 추론을 배울 때 |
| `language_pattern` | 언어 패턴 | 패턴 설명 → 문장 변환 → 예문 확장 | 문법·표현·외국어 패턴을 익힐 때 |
| `vocab_memory` | 어휘 암기 | 의미 묶음 → 기억 단서 → 회상 연습 | 단어·용어·개념 암기가 필요할 때 |
| `reading_argument` | 독해·논증 | 주장 찾기 → 논증 구조 → 근거 판별 | 글의 주장과 근거를 파악할 때 |
| `history_timeline` | 역사 흐름 | 시간축 → 맥락 해석 → 순서 복원 | 사건 순서와 시대 맥락을 배울 때 |
| `humanities_argument` | 인문 논점 | 개념 정의 → 관점 비교 → 논점 적용 | 철학·문학·사회 논점을 볼 때 |
| `law_policy` | 법·정책 | 요건 정리 → 판단 흐름 → 사례 적용 | 규정과 사례 판단을 배울 때 |
| `business_strategy` | 경영 전략 | 전략 문제 → 지표 해석 → 실행 선택 | 경영·마케팅·창업 판단을 할 때 |
| `creative_critique` | 예술·창작 | 작품 읽기 → 표현 구조 → 비평 연습 | 예술·음악·디자인 감상이 필요할 때 |
| `writing_structure` | 글쓰기 구조 | 글의 뼈대 → 문단 흐름 → 문장 고치기 | 답안·에세이·보고서를 쓸 때 |
| `person_profile` | 인물 탐구 | 생애 맥락 → 업적 지도 → 평가 연습 | 학자·통계학자·작가·개발자 등 사람을 배울 때 |
| `statistics_inference` | 통계 추론 | 자료 구조 → 추론 공식 → 해석 판별 | 통계학·회귀·표본·p-value를 배울 때 |
| `research_method` | 연구 방법 | 연구 질문 → 방법 설계 → 한계 점검 | 논문·실험설계·연구방법론을 읽을 때 |

| `astronomy_space` | 천문·우주 | 스케일 지도 → 관측 근거 → 현상 분류 | 천체·우주·블랙홀 같은 스케일 큰 주제를 볼 때 |
| `earth_science` | 지구과학 | 시스템 지도 → 변화 패턴 → 증거 판별 | 지진·화산·기상·판 구조론을 배울 때 |

| `psychology_behavior` | 심리·행동 | 행동 프레임 → 기제 지도 → 사례 적용 | 심리학·행동·인지·동기를 배울 때 |
| `sociology_culture` | 사회·문화 | 현상 정의 → 관계 구조 → 사례 해석 | 사회 현상과 제도, 문화를 볼 때 |
| `geography_region` | 지리·지역 | 공간 지도 → 지역 비교 → 지역 판별 | 공간·도시·지역·인구 흐름을 배울 때 |

## 자유주제 대응 원칙

- 화학·생명·의과처럼 도메인 특성이 강한 주제는 전용 템플릿을 우선 고른다.
- 도메인 전용 템플릿이 없으면 `foundation_overview`, `process_flow`, `cause_effect`, `visual_map` 중 하나로 안전하게 시작한다.
- 코딩 주제는 `concept_code`, `algorithm_trace`, `debug_case`, `system_design` 중 학습 목적에 맞춰 고른다.
- 언어 주제는 `language_pattern`, `vocab_memory`, `reading_argument`, `writing_structure`로 분기한다.
- 사람 이름이나 직업형 주제는 `person_profile`로 먼저 분기해 생애·업적·영향을 분리한다.
- 통계 개념 주제는 `statistics_inference`로 분기해 표본·분포·추론·해석 한계를 분리한다.
- 물리·천문·지구·환경·경제·심리·사회·지리·공학·전자·미디어는 전용 템플릿으로 먼저 잡는다.
- 시험 준비는 과목과 무관하게 `exam_focus` 또는 `memory_drill`을 우선 적용한다.

## 과외식 설명 전략

템플릿은 단순 화면 틀이 아니라 과외 설명 전략과 연결된다.

| 주제군 | 과외 관점 | 설명 순서 |
|---|---|---|
| 기술·공학 | 입력·상태·출력·검증 | 최소 예제 → 변수 추적 → 실패 사례 → 재사용 기준 |
| 과학·건강 | 현상·원리·증거·한계 | 관찰 → 변수 → 원리 → 작은 예측 → 한계 |
| 임상·의과 | 증상·위험신호·감별·주의 | 위험 신호 → 감별 후보 → 검사 이유 → 주의 문장 |
| 수리·통계 | 변수·분포·추론·한계 | 변수 정의 → 시각화 → 추정 → 해석 한계 → 반례 |
| 인문·사회 | 맥락·관점·근거·비판 | 맥락 → 주장 → 근거 → 반론 → 오늘의 적용 |
| 인물 | 시대 문제의식·선택·업적·영향 | 시대 질문 → 핵심 선택 → 방법 → 영향 → 비판 |
| 언어 | 형태·의미·맥락·오류 | 패턴 → 예문 → 대조 → 직접 변환 → 오류 수정 |
| 시험·암기 | 출제언어·판별기준·오답루틴 | 출제 표현 → 기준 표시 → 오답 제거 → 회상 루틴 |

## 시각 계약

모든 템플릿은 `app/template_visuals.py`의 시각 계약을 가진다. 프론트 팔레트만 사용하며, 새 색 체계를 만들지 않는다. 서체는 프론트와 같은 `Pretendard Variable → Pretendard → Inter → system-ui` 순서로 맞춘다.

| 파트 | 역할 | 색상 기준 |
|---|---|---|
| 제목·배지 | 사용자가 템플릿 성격을 즉시 알아보는 지점 | `#207B4C`, `#1664B8`, `#2A3B45`, `#7A6518`, `#C2425B` 중 템플릿군별 선택 |
| 개념 패널 | 정의·핵심 개념·원리 설명 | `#E7F3E8`, `#F3F7FB`, `#F4F0E5`, `#FFF3DA`, `#FDECEF` |
| 실습 패널 | 직접 적용·판별·검증 활동 | `#FFF3DA` 또는 `#E7F3E8` |
| 주의·오해 | 함정, 예외, 한계, 위험 신호 | `#FDECEF` |
| 목록 | 정보 스캔 방식 | `check`, `step`, `metric`, `timeline`, `quote` 중 하나 |

템플릿군별 기본 의도는 다음과 같다.

| 템플릿군 | 예시 | 구획 | 목록 |
|---|---|---|---|
| 기술·공학 | 코드, 알고리즘, 시스템, 전자 | 모델→흐름→구현 | step |
| 과학·건강 | 화학, 생명, 임상, 물리, 환경 | 관찰→원리→검증 | metric |
| 인문·사회 | 인물, 역사, 법, 미디어, 지리 | 맥락→근거→평가 | timeline |
| 분석·수리 | 통계, 데이터, 경제, 수학 | 자료→추론→한계 | metric |
| 시험·암기 | 시험, 디버그, 암기 | 기준→연습→오답 | step |
| 언어·창작 | 언어, 독해, 글쓰기, 예술 | 의도→표현→비평 | quote |

## 안전장치

- 모든 템플릿은 5장 슬라이드와 강의 끝 5개 퀴즈를 분리한다.
- `interactive` 슬라이드는 실습 활동이며 퀴즈로 저장하지 않는다.
- `code` 슬라이드는 `from`, `class`, `def`, 일반 변수를 포함하고 Shiki 또는 Python fallback으로 색상 구분한다.
- 후처리는 코드, Mermaid, KaTeX, 차트, sanitize, iframe 순서로 실행한다.
- 실제 DB INSERT는 Phase 5의 asyncpg DBRouter가 담당하며, 현재 데모는 테이블별 저장 매핑을 미리 보여준다.
