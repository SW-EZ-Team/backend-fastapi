# 슬라이드 채팅 모듈

## 목적

슬라이드 채팅은 일반 챗봇이 아니라 현재 강의·현재 슬라이드·음성대본·핵심노트·튜터 성향을 함께 읽는 동반 과외 모듈이다.

## 입력

- `lesson_id`, `slide_id`, `slide_idx`
- 사용자 질문, 선택 텍스트, 현재 재생 시각
- 튜터 성향과 취약점 스냅샷

## 전처리

1. 질문을 개념, 코드, 차트, 퀴즈, 오개념, 적용 예시로 분류한다.
2. 현재 슬라이드의 역할, 카테고리, 학습초점, 자가점검 질문을 압축한다.
3. 음성대본과 핵심노트를 함께 넣어 “방금 어떻게 설명했는지”를 보존한다.

## 출력

운영에서는 채팅 AI의 token stream을 그대로 프론트 채팅에 흘린다. 데모에서는 같은 인터페이스에서 `mock`과 `codex_cli`를 선택할 수 있다. `codex_cli`는 기존 Codex CLI OAuth 세션을 쓰는 개인 로컬 검증 전용 경로이며, production 모델 라우팅은 바꾸지 않는다. 채팅은 커리큘럼 전체가 아니라 선택한 강의 1개와 현재 5슬라이드 맥락에 묶인다.

## 경계

- 퀴즈 정답 판정은 DB의 `answer_idx`가 기준이다.
- 채팅 AI는 정답을 새로 만들지 않고 왜 맞는지 설명한다.
- iframe HTML 원문은 LLM에 넣지 않고 `semantic_meta`와 대본·노트만 넣는다.
